# Logos

The Favolist mark: three large squares and one quadrant subdivided into four, the bottom pair pink. Geometry measured from the Favolist 4.0 favicon (128px): 60-unit squares, 8-unit gutters, 26-unit small squares. Each file carries its own fills, so it shows via `<img>` in both themes.

- `favolist-mark.svg` — the standard mark: squares in `#19070c` (ink), the two small bottom squares in `#fc467d` (accent-vivid). For light surfaces.
- `favolist-mark-light.svg` — squares in `#f7eff1` (dark-theme ink), pink unchanged. For dark surfaces and over scrims.
- `favolist-mark-ink.svg` — every square in `#19070c`. For single-ink contexts (print, embossing, favicons on pink grounds are not allowed). Recolour by editing the fill.

Clear space is one small square (26/128 of the width) on every side. Minimum size 16px; below that use a single pink square. The wordmark is "Favolist" set in Outfit 700 at −0.02em in `ink`, beside the mark at cap height with a `space-2` gap; the original wordmark SVG lived on Cloudinary and is not included here.
