# Reference

Brand artefacts from Favolist 4.0, kept as the record of where the system comes from. Reference only; do not place these in product UI.

- `favolist-social-cover.png` — the 1200×630 Open Graph cover: mark and wordmark in Outfit 700 on white, the tagline "A social product recommendation & referral network", and a grid of product photos.
