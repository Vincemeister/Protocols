# Checkbox

A 20px square (`radius-xs`, `line-strong` border) that fills `accent` with an `on-accent` check when checked; the label in `body` sits to its right, with an optional `caption` help line under it. The whole row is the hit target, `control` tall at minimum. Use it for multi-select and agreements; a single on/off setting is a Toggle.

The consumer provides `label`, `help`, `checked`, `disabled`, `onChange`. Don't: round checkboxes; checkbox lists longer than about seven items without grouping.
