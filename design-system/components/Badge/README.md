# Badge

One or two words of status or count beside a name: "12 products", "New", "Published", "Draft". `caption` weight 500 on `surface-sunken` with `ink-muted` by default; `accent-soft`/`accent` for "New" or a selected filter; `success-soft`, `warning-soft`, `danger-soft` with their text colours for states. Square corners (`radius-none`), 20px tall, an optional 12px Lucide icon.

The consumer provides `label`, optional `tone` and `icon`. Don't: use a badge as a button; stack more than two on a card; shout deals ("50% OFF") — a referral code lives in CodeFrame, not a badge.
